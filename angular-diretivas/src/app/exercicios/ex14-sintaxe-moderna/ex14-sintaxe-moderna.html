Exercício 14 – Conversão para a sintaxe moderna

Conceitos: @if, @else, @for, @empty e track

Exercício 2 convertido (@if e @else)

@if (usuarioLogado) {

Usuário autenticado

} @else {

Acesso não autorizado

}

Exercício 11 convertido (@for com @if dentro, sem ng-container)

    @for (produto of produtos; track produto.id) { @if (!somenteDisponiveis || produto.quantidade > 0) {
  • {{ produto.nome }} Quantidade: {{ produto.quantidade }}
    • } } @empty {
  • Nenhum produto cadastrado
    • }

Exercício 13 convertido (@for, @empty e @if/@else)

    @for (tarefa of tarefas; track tarefa.id) {
  • {{ tarefa.titulo }} Responsável: {{ tarefa.responsavel }}
    @if (tarefa.concluida) { Concluída } @else { Pendente }
    • } @empty {
  • Nenhuma tarefa cadastrada
    • }

Duas diferenças percebidas entre as sintaxes

  1. A sintaxe moderna usa blocos (@if, @else, @for) escritos como o controle de fluxo de uma linguagem de programação, e faz parte do próprio template: não é preciso importar CommonModule (NgIf/NgFor). Também acabam o ng-template com referência (#) para o else e o ng-container para combinar repetição e condição, o que deixa o código mais curto e legível.
  2. No @for o track é obrigatório e o tratamento de lista vazia (@empty) já vem embutido, sem precisar de um segundo ngIf com tamanho da lista. No *ngFor o trackBy era opcional e exigia uma função separada; agora basta informar uma propriedade identificadora, como produto.id.
